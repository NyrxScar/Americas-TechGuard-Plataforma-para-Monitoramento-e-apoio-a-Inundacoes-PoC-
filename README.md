# Americas-TechGuard-Plataforma-para-Monitoramento-e-apoio-a-Inunda-es-PoC-
Prova de conceito (PoC) de uma plataforma inteligente para monitoramento de enchentes e resposta a emergências, integrando comunicação híbrida de IoT (LoRaWAN e Meshtastic), computação de borda, visualização geoespacial, análise de risco, alertas ambientais e suporte à decisão para cidadãos e agências de defesa civil.
